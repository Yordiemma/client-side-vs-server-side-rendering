# Client-Side vs Server-Side Rendering

## Project Description

This project demonstrates the difference between **Server-Side Rendering (SSR)** and **Client-Side Rendering (CSR)** using plain HTML, CSS, and JavaScript.

Two versions of the same webpage were created:
- `ssr.html` – content is present in the HTML at page load
- `csr.html` – content is rendered using JavaScript in the browser

Both pages use the same design, layout, and data.  
The only difference is how the content is rendered.

---

## Files Included

- `ssr.html` – Server-Side Rendering example
- `csr.html` – Client-Side Rendering example
- `csr.js` – JavaScript used to render content for CSR
- `style.css` – Shared styling for both pages
- `analysis.md` – Written comparison of SSR and CSR

---

## How to View the Project

1. Clone or download the repository
2. Open `ssr.html` in a web browser
3. Open `csr.html` in a web browser
4. Compare how the pages load and display content

No build tools or frameworks are required.
